# v1.27.1 — 搜索结果加载更多

## 本次修复

- 全日期搜索不再只能查看最近 60 条：点击“加载更多”逐批追加结果，显示已加载数和总数。
- 追加时保留已有结果和滚动位置，新增结果也可以回到原消息。
- 加载期间防止重复点击；失败保留已有结果并提供“重试加载”，全部加载后隐藏按钮。
- 切换群、关键词、搜索范围或关闭面板后，旧分页响应不会混入新结果。
- 重叠结果按日期与消息 ID 去重；异常空页停止追加并提示重新搜索。

## 使用边界

- 此次只完善结果分页，不新增日期范围或发言人筛选，不改变搜索排序和后端接口。
- 分页使用 offset，不提供搜索快照；搜索过程中新增或删除归档消息可能影响结果，重新搜索可获取最新列表。
- 不迁移聊天数据，不增加运行时依赖。

## 验证

- `npm run check`：lint、327 个单测及合成切群烟测。
- `node scripts/check-archive-ui.js`：52 组浏览器检查，覆盖 135 条结果的 60→120→135 追加、100 条的 60+40、失败重试、请求隔离、末页和手机布局。
- 浏览器验证使用合成数据和本地生成头像，不访问真实群聊或付费模型。

## 安装与升级

- macOS Apple Silicon：下载 `weibo-chat_v1.27.1_aarch64.app.zip`，解压后替换旧应用；应用未签名，首次启动需按系统提示允许打开。
- 网页版：更新仓库，运行 `npm ci`，重启 `npm run view` 并刷新页面。
- 不新增其他桌面平台安装包；未宣称已完成真实 macOS 交互或微博接口实机验收。
