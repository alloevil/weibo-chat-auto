# v1.27.0 — 群聊档案馆、代码日志模式与阅读位置记忆

## 本次更新

- **群聊档案馆界面**：石墨色工具区、白色阅读区和浅灰辅助面板；统一群选择器支持群名搜索，取消常驻群列表。
- **历史导航**：最近 7 个归档日直接展示，更早记录按年/月折叠；日期选择器按需打开，检索结果可回到原消息。
- **紧凑对话流**：连续发言视觉分组，保留逐条消息定位；长引用可展开，手机通过消息菜单查看完整时间和上下文。
- **阅读与追更分开**：支持最新归档、当天底部及新增记录提示；后台更新不自动打断历史阅读。
- **代码日志外观模式**：顶部 `</>` 或 **Alt+Shift+X** 切换，用等宽字体、行号和中性来源编号阅读；切回恢复普通界面与草稿。
- **每群阅读位置记忆**：切群和刷新恢复日期与消息位置；按消息 ID 定位，前方补录记录不依赖旧像素高度。

## 使用与边界

### 代码日志模式

- 顶部 `</>` 或 **Alt+Shift+X** 进入；使用同一快捷键或代码视图右上角 **View** 按钮退出。
- 隐藏群名、昵称标签、头像、图片、发送框和聊天弹窗；**正文仍然可见，不会自动脱敏**。
- 不新建应用消息/摘要通知，不请求通知权限；不能撤回已发出的系统通知，也不隐藏浏览器地址、历史或原生窗口名称。
- 不取消已经发出的同步/发送请求。**Escape 不退出模式；刷新恢复普通视图。**
- 这是外观模式，不是访问控制、加密或可靠的防窥保护。

### 阅读位置

- 位置存储在当前浏览器来源的 `localStorage`，只记录群标识、日期、消息 ID 和偏移，不保存正文或草稿；不跨设备同步。
- 原消息不存在时回到当天开头，日期不存在时回到最新归档；主动选日期、来源跳转和“最新归档”优先。
- 同次退出代码模式仍恢复进入前普通视图的位置；在代码模式下刷新，则按最后读到的消息恢复普通视图。
- 本地存储不可用时，仅保留本次会话内的位置；切群清空发送草稿的既有行为不变。
